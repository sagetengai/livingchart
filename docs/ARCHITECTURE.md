# Architecture Overview

- `src/` – front‑end source (HTML, CSS, JS).
- `config/` – JSON configuration for map extent and theme tokens.
- `data/` – raw source downloads, processed assets, and demo wind data.
- `scripts/` – Python utilities to prepare bathymetry and generate contours.
- `tests/` – Jest unit tests for JavaScript modules.
- `package.json` – npm scripts and dev dependencies.
